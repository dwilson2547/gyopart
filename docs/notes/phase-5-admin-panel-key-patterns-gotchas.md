Admin API lives in gyopart/junkyard-platform/admin_api/. Port 8101. Auth was removed in commit 179aad8 (network boundary sufficient); _ADMIN_KEY stub (None) kept in main.py so _patched_client() tests can patch it. Two routers in discrepancies.py: router (prefix=/admin/discrepancies) and admin_router (prefix=/admin) — the latter exposes GET /admin/pi-models. _get_pi_engine dep pattern: import _pi_engine from main inside the function. Engine created in lifespan (statement_timeout=10000). Three UI pages via _ui_router in main.py (prefix=/admin/ui): /discrepancies, /rules, /llm-queue. Templates in admin_api/templates/ (Jinja2 + HTMX 1.9.12 from CDN). HTMX gotcha: setting Content-Type: application/json in hx-headers does NOT change how HTMX encodes form body — still sends URL-encoded. Fix: accept Form(...) params in the route. hx-vals null encoding gotcha: JSON null in hx-vals becomes the STRING 'null' in URL-encoded form data (via URLSearchParams). Fix: use a mini-form with conditional hidden inputs instead of hx-vals, so absent fields are truly absent (FastAPI Form(None) gets Python None). Deactivate HTMX pattern: return Response(content='', status_code=200) for HTMX calls; HTMX outerHTML swap with empty body removes the target element from DOM. OOB swap pattern for empty-state paragraphs: add <p id='rules-empty' hx-swap-oob='true' style='display:none'></p> in _rule_row.html partial; HTMX processes OOB swaps automatically. Source field in discrepancy inline rule form: hidden input #rule-source-N populated by toggleRuleForm JS; scope='source' gets group's source value, scope='global' gets empty string. 38 tests pass (39 total minus 1 pre-existing auth failure).
