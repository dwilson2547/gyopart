## Workflows
1. Triage discrepancies — reason tabs with counts, filter by yard/make/search, paged group list, open a group.
2. Map a decode group — pick catalogue model(s) (suggested + searchable, cross-make toggle), year range, series scope, preview, confirm → mapping rows + requeue; group leaves the list.
3. Ignore / reopen a group.
4. Catalogue-gap groups by yard — per-yard and per-year breakdown + catalogue coverage (yard trends).
5. Yard rule for no-decode groups — fix make or model of the yard's own strings, target picked, scope this yard / all yards, preview, confirm.
6. Mappings & rules page — list with vehicle counts, delete with confirmation (requeues affected vehicles).
7. Find a vehicle — search by VIN / stock number from the top bar; open one from a group's sample cars.
8. Vehicle page + re-match — yard data, NHTSA decode, match state (method, candidates as catalogue names, reason);
   Re-match requeues it and the page shows the new result.
9. Manual match — cascading year → make → model → car (trim + engine) pickers over the catalogue, prefilled from
   the decode / yard data; saves the exact catalogue car.
10. Re-scrape the yard — Run now on the vehicle's yard ScrapeJob via scrape-job-manager, with the job's state.
