# Junkyard admin UI — design

Source: `../docs/admin-rewrite-design.md` (agreed 2026-10-15). Phase 2 scope: §2.3 + §2.5, LAN/dev only.

## What it is for
Get every yard vehicle matched to catalogue cars: see why the unmatched ones didn't match and fix the cause
by picking the right catalogue value, then watch the vehicles match within seconds.

## Hero flow (80%)
Open the Fixable tab → click the biggest group → pick the catalogue model(s) it means → preview → confirm.
Repeat. Everything else (gaps, ignored, mappings list) is secondary.

## Hero surface
Two panes. Left: group list for the current tab (decode make / model / series, years, vehicles, yards),
largest first, filters on top. Right: the selected group's detail with the fix panel open — suggestions as
one-click chips, the combobox, the preview result and the Confirm button all visible without scrolling.
Tabs + counts across the top. Mappings page is one nav link away.

## What the system already knows (never typed)
- The decode side of a mapping: make/model/series come from the group.
- Year range: defaults to the group's min..max years.
- The target make: the decode's make (catalogue spelling) unless "different make" is toggled.
- Candidate targets: catalogue models of that make that exist in the year range, ranked by similarity.
- Yard rules: the raw value is the group's exact yard string; scope defaults to the group's yard.
- Created-by: the signed-in user later (phase 4); "admin" until then.

## Workflow Requirements

### 1. Triage discrepancies
- Data: tab counts per reason bucket (Fixable = model_not_in_catalogue + make_not_in_catalogue; Catalogue
  gaps = year_not_in_catalogue + model_year_gap; No decode = no_vin + decode_failed; Ignored). Groups: key,
  reason, years min–max, vehicle count, yard count. Active vehicles only.
- Actions: switch tab (URL keeps tab/filters), filter by yard (combobox), make (combobox), text search,
  page, select a group.
- Empty: per tab — "Nothing to fix here" / "No catalogue gaps" etc., plus "clear filters" when filtered.
- Error: inline banner above the list, retry button; list keeps the last data.
- Success: n/a (read). Loading: skeleton rows; panel shows "loading…".

### 2. Map a decode group
- Data: group detail (per-yard counts, per-year counts, sample vehicles with VIN/yard/stock), catalogue
  coverage for the make, suggestions (model, year span, similarity), existing mappings for this decode.
- Actions: toggle suggestion chips (multi-select), add via combobox (models of target make in year range;
  "show all years" switch), toggle "different make" (make combobox), edit year from/to (prefilled), series
  scope radio (this series only / any series; only shown when the group has a series), Preview, Confirm.
- Empty: no suggestions → "No catalogue model of <make> in <years>; try another make or widen years".
- Error: preview/confirm errors inline under the button (validation: no targets, year_from > year_to,
  target not in catalogue → 422 shown at the field).
- Success: preview shows "N vehicles · M would match (K exactly)" + reasons after; Confirm → toast
  "Mapped: N vehicles requeued", group removed from list immediately, counts refresh; next group selected.

### 3. Ignore / reopen
- Actions: Ignore (confirm inline: "Ignore N vehicles?"), in Ignored tab: Reopen.
- Success: group leaves current list immediately, toast, counts refresh. Error: inline banner in panel.

### 4. Catalogue-gap groups by yard
- Data: same group detail; per-yard breakdown prominent; catalogue year coverage for make and for the
  decode model (bar of years the catalogue has vs years in yards).
- Actions: filter tab by yard; mapping panel still available (some gaps are naming), Ignore.
- Empty/error as 1.

### 5. Yard rule (no-decode groups)
- Data: group key = yard + raw make/model; sample vehicles; suggestions for make (catalogue makes ranked)
  and model (models of chosen make ranked).
- Actions: choose what to fix (make / model / both), pick targets via combobox, scope radio (this yard /
  all yards), Preview (fuzzy match with rule applied), Confirm.
- Empty: no-decode tab empty → "Every vehicle has a usable VIN decode".
- Error/success: as 2.

### 6. Mappings & rules page
- Data: mappings (decode → catalogue, series, years, vehicles with that decode now: total / matched,
  created by/at); rules (yard/global, field, raw → canonical, applied count).
- Actions: filter text; delete (inline confirm: "Delete and re-match N vehicles?").
- Empty: "No mappings yet — create them from the Discrepancies page" with link.
- Error: banner. Success: row disappears immediately, toast with requeued count.

## Non-negotiables check
Comboboxes for every catalogue field (makes ~70+, models hundreds); inline errors; immediate refresh after
mutation; confirm before ignore/delete; empty + loading states everywhere; dark by default.

## Phase 3 — vehicle page (design §2.4)

Hero flow: from a group, click a sample car → see why it didn't match (decode vs catalogue) → re-match, or
pick its exact catalogue car, or re-scrape its yard if the yard data looks stale/wrong.

What the system already knows: the vehicle's year (prefills the year picker), the decode's make/model
(prefill make, highlight the decode's model names), the yard (→ its ScrapeJob, no typing).

### 7. Find a vehicle
- Data: up to 20 hits: year make model, yard, stock, VIN, matched or not.
- Actions: top-bar search (VIN full or partial ≥ 5 chars, stock number exact, vehicle id), Enter → results
  dropdown / single hit opens directly; sample-car rows in a group link to the vehicle.
- Empty: "No vehicle with that VIN or stock number." Error: inline under the box.

### 8. Vehicle page + re-match
- Data: header (year make model trim, yard location + source, stock, row, arrived, VIN); Match card (method,
  confidence, candidates with catalogue year/make/model/trim/engine, or the discrepancy reason + decode);
  NHTSA decode (key fields; full record collapsible); yard fields (all non-empty columns + extras).
- Actions: Re-match (no confirm: harmless, re-runs the matcher) → "re-matching…" then the new result
  (poll until resolve_attempted_at changes, max ~30 s, then "still queued" with a refresh button).
- Empty: no decode → "No VIN" / "VIN didn't decode" explained. Error: banner + retry; 404 → "No such vehicle".

### 9. Manual match
- Data: comboboxes: year (catalogue years), make (makes with cars that year), model (models of that make that
  year), car (trim · engine, with car id); prefilled from vehicle year + decode make; decode model names first.
- Actions: pick down the cascade (changing a level clears the ones below), Save (confirm inline: "Set this car
  by hand? Re-matching won't change it."). Undo = Re-match (clears the manual choice).
- Errors inline (car not in catalogue = 422 at the car field). Success: toast, Match card shows "manual".

### 10. Re-scrape the yard
- Data: the yard's ScrapeJob (name, phase, last run result/time, next run, running now?), from the cluster.
- Actions: "Run <job> now" (confirm inline: it scrapes the real site) → toast; job state refreshes.
- Empty/error: no ScrapeJob found for this yard → say so (no button); cluster unreachable → message, no button.
